eCommerce Mobile App – Expo (React Native)

Mobile eCommerce application built with Expo (React Native), extending the web platform to mobile devices.

✨ Features

Mobile-first UI

Shared business logic with web app

Product listing

Scalable architecture (in progress)

🛠 Tech Stack

Expo

React Native

TypeScript

⚙️ Setup
git clone https://github.com/mariusherlea/ecommerce-mobile.git
cd ecommerce-mobile
npm install
npx expo start
